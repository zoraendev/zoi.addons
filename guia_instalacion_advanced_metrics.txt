================================================================================
  GUIA TECNICA DE INSTALACION: MODULO ADVANCED METRICS (REPORTES)
  Version: 2.0 (FIFO + Excel Optimizado)
  Compatibilidad: Odoo 17 (Enterprise y Community)
================================================================================

Este documento describe el procedimiento paso a paso para instalar el modulo 
'advanced_metrics' en un servidor Odoo virgen o existente.

--------------------------------------------------------------------------------
1. PRE-REQUISITOS DEL SISTEMA
--------------------------------------------------------------------------------

- Sistema Operativo: Linux (Recomendado Ubuntu 20.04+)
- Odoo: Version 17.0 configurada y funcionando.
- Librerias de Python: 
  El modulo requiere 'xlsxwriter' para generar los reportes de produccion.
  
  COMANDO DE INSTALACION:
  # Asegurese de usar el entorno virtual (venv) de su Odoo
  $ source /ruta/a/su/odoo-venv/bin/activate
  $ pip install xlsxwriter
  
  # Si no usa venv:
  $ sudo pip3 install xlsxwriter


--------------------------------------------------------------------------------
2. PREPARACION DE ARCHIVOS
--------------------------------------------------------------------------------

La carpeta del modulo 'advanced_metrics' debe tener la siguiente estructura 
minima obligatoria para que Odoo la reconozca:

advanced_metrics/
├── __init__.py
├── __manifest__.py
├── controllers/
│   ├── __init__.py
│   └── controllers.py
├── models/
│   ├── __init__.py
│   └── report_wizard.py
├── static/
│   └── src/
│       └── js/
│           └── sales_orders_report.js
└── views/
    └── sales_orders.xml


--------------------------------------------------------------------------------
3. CARGA AL SERVIDOR (DESPLIEGUE)
--------------------------------------------------------------------------------

Paso A: Copiar la carpeta 'advanced_metrics' al directorio de 'addons' del 
servidor destino.

EJEMPLO USANDO SCP (Desde su terminal local):
$ scp -r ./advanced_metrics usuario@ip_servidor:/opt/odoo/odoo17/addons/

Paso B: Ajustar permisos (CRITICO). Odoo debe ser el dueño de los archivos 
para poder leerlos y ejecutarlos.

COMANDOS EN EL SERVIDOR:
$ sudo chown -R odoo:odoo /opt/odoo/odoo17/addons/advanced_metrics
$ sudo chmod -R 755 /opt/odoo/odoo17/addons/advanced_metrics


--------------------------------------------------------------------------------
4. ACTIVACION EN LA INTERFAZ DE ODOO
--------------------------------------------------------------------------------

1. Inicie sesion en su Odoo con privilegios de Administrador.
2. Active el MODO DESARROLLADOR:
   - Ajustes > Bajar hasta el final > "Activar modo desarrollador".
3. Valla al menu "Aplicaciones".
4. Haga clic en el menu superior: "Actualizar lista de aplicaciones".
5. En la barra de busqueda, borre el filtro "Aplicaciones" y busque: 
   "advanced_metrics"
6. Haga clic en el boton "INSTALAR".


--------------------------------------------------------------------------------
5. VERIFICACION POST-INSTALACION
--------------------------------------------------------------------------------

- Valla al menu "Advanced Metrics".
- Verifique que aparezca la pestaña "Ordenes de venta".
- Pruebe el boton "Semana Siguiente" (Debe cargar fechas automaticamente).
- Haga una descarga de prueba de Excel.

NOTA SOBRE ERRORES COMUNES:
- Si el Excel no descarga: Verifique que instalo 'xlsxwriter' en el mismo 
  Python donde corre Odoo (paso 1).
- Si no ve el boton "Semana Siguiente": Refresque el cache del navegador (Ctrl+F5)
  para que el archivo Javascript se cargue correctamente.
