DOCUMENTACIÓN TÉCNICA: BLINDAJE DE SEGURIDAD API - ADVANCED METRICS
======================================================================
Fecha: 06 de Abril, 2026
Estado: Implementado y Asegurado

1. RESUMEN
Esta documentación detalla los cambios de seguridad aplicados a los
controladores de 'inventory_dashboard'. El objetivo principal fue eliminar
el acceso público y transicionar a un sistema estricto de autenticación
basado exclusivamente en Cabeceras HTTP (Headers).

2. ESTRATEGIA DE AUTENTICACIÓN
La API ya NO acepta tokens a través de parámetros de URL (?token=...).
Esto evita que las claves queden registradas en el historial del
navegador, logs del servidor o servidores proxy.

ENCABEZADOS SOPORTADOS:
- Access-Token: (Recomendado) Cabecera personalizada con el UUID.
- Authorization: (Estándar) Formato "Bearer <token>".

3. IMPLEMENTACIÓN TÉCNICA
Se añadió el método privado '_authenticate' al controlador principal.
Este método realiza las siguientes acciones:
  a. Busca el token en los metadatos de la petición.
  b. Limpia el formato si se envía como 'Bearer'.
  c. Valida la existencia del token en el modelo 'advanced_metrics.api.config'.
  d. Si no es válido, corta la ejecución inmediatamente.

4. ENDPOINTS PROTEGIDOS
Los siguientes servicios ahora requieren obligatoriamente el token:
- POST /api/bi/inventory-intelligent/top-products
- POST /api/bi/inventory-intelligent/products-sales
- POST /api/bi/inventory-intelligent/sales-trend
- POST /api/bi/inventory-intelligent/dead-products
- POST /api/bi/inventory-intelligent/high-rotation-products

RESPUESTA EN CASO DE ERROR:
Si el token es inválido o está ausente, el servidor responderá con:
Status: 401 Unauthorized
Mensaje: "Acceso no autorizado: Token invalido o ausente en las cabeceras."

5. SEGURIDAD DEL ENTORNO (Git)
Se actualizó el archivo '.gitignore' para incluir reglas de exclusión
estrictas para archivos de Postman, evitando la subida accidental de
colecciones con datos sensibles o claves de desarrollo.

6. GUÍA RÁPIDA PARA DESARROLLADORES
Para consumir estos servicios desde herramientas externas (Power BI, scripts):
Añadir la cabecera:
  Key: Access-Token
  Value: [Tu-UUID-Generado-en-Odoo]
