# Zoraen Analitics

Addon base para centralizar:

- hubs de analitica
- reporteria y analisis
- dashboards dinamicos
- procesamiento de datos para metricas

## Alcance inicial

Este addon nace como una base liviana separada de `zrn_prodigyn`, sin mover todavia la logica analitica pesada ni los hubs reales.

Incluye:

- app propia de Zoraen Analitics
- pantalla principal con dos paginas
- workspace reservado para hubs y dashboards futuros
- assets minimos de color y estructura visual

## Objetivo funcional

Permitir que la capa analitica tenga desde el inicio:

- punto de entrada propio
- navegacion desacoplada
- base visual consistente
- espacio preparado para crecer por dominios analiticos
