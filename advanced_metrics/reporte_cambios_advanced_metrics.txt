# REPORTE DE CAMBIOS TÉCNICOS: MÓDULO ADVANCED_METRICS
# Fecha: 2026-03-29
# Estado: Instalación Exitosa en Odoo 17

INTRODUCCIÓN:
Se detectó que el módulo original presentaba fallos críticos de carga de XML debido a referencias cruzadas no resueltas. El módulo fue corregido y desplegado en el servidor 192.168.0.42.

DETALLE DE MODIFICACIONES:

1. MANIFEST (__manifest__.py):
   - Cambio: Se reordenó la lista 'data'.
   - Orden original: sales_orders.xml -> views.xml.
   - Orden nuevo: views.xml -> sales_orders.xml.
   - Motivo: sales_orders.xml hereda de una vista definida en views.xml. Sin este orden, Odoo arroja error "External ID not found".

2. PANTALLA PRINCIPAL (views/views.xml):
   - Cambio: Inserción de 'action_advanced_metrics_report_wizard'.
   - Motivo: El botón "Abrir" del Dashboard (línea 64) invocaba esta acción. Al estar definida originalmente en otro archivo, el sistema fallaba si no se cargaba en el orden exacto. Se centralizó la acción para garantizar que esté disponible al crear el Dashboard.

3. HERENCIA DE VENTAS (views/sales_orders.xml):
   - Cambio: Actualización de 'ref' en inherit_id.
   - Antes: ref="view_advanced_metrics_inicio_form".
   - Después: ref="advanced_metrics.view_advanced_metrics_inicio_form".
   - Motivo: Cumplimiento de estándares de Odoo 17 para evitar colisiones de nombres y asegurar la resolución correcta del ID externo entre archivos.
   - Limpieza: Remoción parcial de definiciones redundantes para evitar conflictos de sobreescritura.

RESULTADO FINAL:
Módulo instalado correctamente. El menú "Advanced Metrics" es ahora funcional y accesible desde la interfaz web de Odoo.
